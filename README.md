# ClearPath Review

A product exploration for improving marketing-compliance review at **ClearPath Financial**, a fictional consumer-finance company offering personal loans, credit cards, and mortgage prequalification.

## Current status

Research and product planning. No application has been implemented or deployed yet.

Start with the [research and product direction document](docs/research.md). It covers the likely Excel/email workflow, the judgments reviewers make, three candidate products, their tradeoffs, and the proposed scope and acceptance criteria for a 24-hour prototype.

The current recommendation is a **Revision and Approval Inbox** with a small, evidence-backed compliance review layer. This most directly addresses the effort of keeping submissions, revisions, outstanding issues, and decisions aligned across Excel and email. The implementation scope remains open for discussion.

## Repository purpose

This repository will contain the research, application code, verification, and deployment instructions for the project. Findings distinguish published source evidence from assumptions about the fictional company.

- [Research, alternatives, and tradeoffs](docs/research.md)
- Application and setup instructions: to be added after scope selection.

All proposed offer terms and demonstration cases are fictional. No consumer data is needed for the prototype.
