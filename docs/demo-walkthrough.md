# A correction round, then an exact decision

Use fictional material only. The reviewer dashboard has no sign-in; participant names are simulated. Seeded findings are authored examples. A fresh submission starts without findings.

1. **Submit as an affiliate.** Open `/submit` in a separate tab. Upload [the original social image](../public/fixtures/loan/v1/social-ad.png), describe the promoted offer and intended use, and save. Keep the receipt's return link. The affiliate does not select an internal authority or enter the queue.
2. **Review as ClearPath.** Open the case from **Review queue**. Select the personal-loan reference and confirm intake. Compare the image with the cited source. Add a submitter-facing fee correction and a separate destination evidence request. The basis stays internal; requested actions can be shared. A source page remains visible while editing.
3. **Share specific requests.** **Prepare feedback** groups required corrections and advice. Edit and save the draft, reopen it if needed, then choose **After sharing, wait for a response**, confirm who acts next, and **Share feedback on submission link**. Saving a draft alone does neither. Refresh the return page: all shared requests remain available, including earlier batches, while internal questions stay absent. Sharing does not send email; actual outside communication has its own record.
4. **Return a partial correction.** On the return page, choose **Submit updated package** and **Replace** the image with [v2](../public/fixtures/loan/v2/social-ad.png). Save a revision note. In the reviewer workspace, confirm the new package and inspect **Versions**. Resolve only the fee finding with its evidence. The missing destination continues to block approval.
5. **Return evidence and finish the package.** Reply to the destination request with [the two-page destination PDF](../public/fixtures/loan/v3/destination.pdf). The waiting case appears in **To review**. Open the answer and PDF beside the current creative; receiving a file has not resolved anything. If the PDF represents the destination receiving approval, open a new internal revision, explicitly include the response file with the Destination role, and keep the corrected image. Confirm intake and inspect both pages. Record a disposition using the relevant response, explicitly return the case to its reviewer if appropriate, and optionally share the request's status. Other requests remain independent.
6. **Decide, share, retrieve.** Record the exact scope and rationale with a fresh human-review acknowledgment. Open **View decision** to see the preserved package and basis. The queue still shows communication due. Prepare and share the result, or record outside communication of the exact saved message version linked to that decision. The return page shows a shared decision's reviewed creative/destination and scope, without internal rationale. A later revision does not inherit approval. Withdrawal preserves the original record and marks a shared approval withdrawn.

**History & notes → Download internal record** downloads a ZIP with original files, source documents, package versions, decisions, and handoff records. It excludes return-link tokens and private note records. It includes internal reasoning and manually communicated message versions, so it is not a submitter packet.

For a shorter presentation, use **Make room for what’s next**. Its legacy findings start Internal: deliberately change Audience to Submitter before sharing. The migration does not guess what was previously communicated. New references can be added through **Offer references**, with manually entered facts linked to uploaded source pages.

Credit cards and mortgage prequalification share this workflow. The card's matching annual-fee fact is not legal clearance; a reviewer still has to assess advertising requirements. PNG/JPEG and PDFs have previews; other formats are preserved for download. No detection, extraction, or live-web capture is implied.

For the decision in step 6, demonstrate a bounded scope: for example, the named affiliate's paid-social placement for a stated audience and geography, between stated dates, using only this revision's image and destination for the selected product. These are demonstration assumptions, not verified campaign facts. Leave unknowns explicit and explain any exclusions. The app preserves that scope; it does not certify state-law coverage or stop use after an end date.

The card sample now has one required finding for its unfinished disclosure review, including both the image and caption. Its reference is intentionally incomplete. It is a useful second example of an evidence request, not an alternative already-approved campaign.

If a stale save occurs, entered work stays available and the latest context loads. Internal and external revision drafts preserve actual edits and require explicit choices when they conflict with the new package. Recheck file retention and replacement choices before retrying. Decision acknowledgment resets; an open reply must be checked again if its package or decision changes. Unfinished text is kept for this tab session. Uploads require reselecting after a browser restart.
